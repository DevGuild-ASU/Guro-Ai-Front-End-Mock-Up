# MOCK / STATIC WEB DASHBOARD

This folder contains all mock-up and static dashboard components for the
Guro AI web application. These files represent the current UI/UX prototype
and are subject to change during active development.

## Contents

- `dashboard/` — Main dashboard layout and its sub-components.
- `dashboard/css/` — Styles scoped exclusively to mock dashboard views.

## Mock-up Specifications

- **Static Data**: All data displayed is hardcoded for prototyping.
- **No Backend**: Components do not connect to any API or database.
- **Placeholder Routes**: Routes exist but are not yet wired to real logic.
- **Design References**: See `references/WEB_REFERENCE.jpg` and
  `references/PHONE_REFERENCE.jpg` for intended visual fidelity.

Do not treat these components as production-ready code.
